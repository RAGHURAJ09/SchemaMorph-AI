SchemaMorph-AI

Complete Project Requirements & Setup Guide
Generated: September 2, 2026 | Version 1.0.0

1. Project Overview

SchemaMorph-AI analyzes monolithic PostgreSQL schemas and discovers natural microservice boundaries using graph analysis (NetworkX + Louvain clustering) and Gemini AI narration.

Backend

FastAPI + Python 3.11+
SQL parsing (sqlglot) → Graph (NetworkX) → Clustering (Louvain) → AI (Gemini) → Validation → Report

Frontend

React 18 + Vite + Tailwind CSS
React Flow graph visualization, service panels, query diff view, markdown export

3. Step-by-Step Setup Instructions

Step 1: Get a Free Gemini API Key

  1. Go to https://aistudio.google.com
  2. Log in with any Google/Gmail account
  3. Click "Get API key" (top left or top right)
  4. Click "Create API key in new project"
  5. Copy the generated key (starts with AIzaSy...)
  6. Free tier: 15 Requests/Minute, 1,000,000 Tokens/Minute

Step 2: Generate a Secure SECRET_KEY

Run one of these commands in your terminal:

# Python
python -c "import secrets; print(secrets.token_hex(32))"

# PowerShell (Windows)
[guid]::NewGuid().ToString("N") + [guid]::NewGuid().ToString("N")

Copy the 64-character hex string output.

Step 3: Configure Environment Variables

Create/edit the .env file in the project root:

# ── AI Engine ────────────────────────────────────────── GEMINI_API_KEY=AIzaSyYourActualKeyHere # ── JWT Security ─────────────────────────────────────── SECRET_KEY=9f8a7b6c5d4e3f2a1b0c9d8e7f6a5b4c3d2e1f0a9b8c7d6e5f4a3b2c1d0e9f8a # ── Database (default: local SQLite — zero setup) ─────── DATABASE_URL=sqlite:///./schemamorph.db # ── CORS ──────────────────────────────────────────────── ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000,http://localhost

Step 4: Start the Backend

cd backend
python -m venv venv
# Windows:
.\venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
python run.py
# → http://localhost:8000
# → API docs: http://localhost:8000/docs

Step 5: Start the Frontend

cd frontend
npm install
npm run dev
# → http://localhost:5173

4. Optional: Supabase Cloud Database Setup

When to use: Only if you need persistent cloud storage across deployments. Local SQLite works fine for development and demos.
  1. Go to https://supabase.com and sign up with GitHub or Google
  2. Click "New Project", select organization
  3. Enter details:
    • Name: SchemaMorph-AI
    • Database Password: Set a strong password (save it!)
    • Region: Closest to you
  4. Wait ~2 minutes for initialization
  5. Go to Project Settings → Database → Connection String → URI
  6. Copy the URI and replace placeholders: 
    postgresql://postgres.[project-ref]:[YOUR-PASSWORD]@aws-0-[region].pooler.supabase.com:6543/postgres
  7. Set in .env: 
    DATABASE_URL=postgresql://postgres.abcdefghijk:MyPassword123@aws-0-us-east-1.pooler.supabase.com:6543/postgres

5. Optional: Production Deployment

Backend → Render

  • Push to GitHub
  • Create Web Service on Render
  • Set environment variables in Render dashboard
  • Build command: pip install -r requirements.txt
  • Start command: uvicorn app.main:app

Frontend → Vercel

  • Push to GitHub
  • Import on Vercel
  • Update vercel.json with your Render backend URL
  • Auto-deploys on push
NOTE: The frontend/vercel.json currently has a placeholder URL (REPLACE-WITH-YOUR-BACKEND.onrender.com). You must replace this with your actual Render backend URL before deploying.
